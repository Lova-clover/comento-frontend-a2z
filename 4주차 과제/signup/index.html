Week4 Project#2 · ID 중복체크 · 비밀번호 규칙

계정 생성

이 과제는 프론트엔드 단독 예제이며, 가입 정보는 브라우저 LocalStorage에 저장됩니다.

1~20자
규칙: 4~16자, 영문 시작, 영문/숫자/._ 만 허용
8~20자
영문 + 숫자 포함
특수문자 1개 이상
공백 금지
같은 문자 3회 연속 금지
테스트 방법
  1. 아이디 입력 후 중복확인을 먼저 수행
  2. 비밀번호 규칙이 모두 만족되면 점이 초록색으로 변함
  3. 가입 완료 후 같은 아이디로 다시 중복확인하면 중복 처리
저장소 안내
LocalStorage 키: week4_users_v1
비밀번호는 브라우저 내 SHA-256 해시(가능한 환경에서)로 저장합니다.
